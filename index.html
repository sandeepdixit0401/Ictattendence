Firebase Setup

एक बार सेटअप → सभी कंप्यूटर पर same data

कैसे करें (3 मिनट):
1. Firebase Console खोलें → Create Project
2. Project बनने के बाद </> (Web) icon क्लिक करें → App Register
3. जो firebaseConfig दिखे उसे पूरा कॉपी करें
4. नीचे Paste करें → Save & Continue
5. Firebase में Realtime Database → Create → Start in test mode
